# PomoSingle

ポモドーロタイマーと一体になった、シングルタスクのためのタスク管理アプリ (Windows / 単体 exe)。

集中中は今やる 1 件だけを見せる。思いついたことと割り込みは一時メモに逃がし、小休止のときにまとめて振り分ける。この運用をアプリの構造で支える。

## 画面

| 画面 | いつ | 見えるもの |
| --- | --- | --- |
| **Quick Capture** | いつでも (ホットキー `Ctrl+Alt+Space`) | 入力欄だけ。Enter で一時メモに入り、元のアプリに戻る |
| **Focus View** | 集中中・小休止中 | タイマーと着手中のタスク 1 件。小休止中は一時メモの振り分け |
| **管理画面** | それ以外 | タスク一覧、一時メモ、定型、設定 |

## 使い方

### 朝の整理

その日最初に管理画面を開くと、一覧の代わりに「朝の整理」が出る (設定で切れる)。3 分ほどで終わる。

1. **動いていないタスクを見直す**。7 日以上動きのない親タスクを、古い順に 1 件ずつ最大 5 件出す (期限が今日以降のもの・定型・待ちは出ない)。「今日やる / 日付を決める / 分解する (最初の一歩をサブタスクに) / 待ちにする / いつかへ / 捨てる / このまま残す」のどれかを押す (1〜7 のキーでも押せる)。
2. **今日やる 3 件を選ぶ**。選んだ順に一覧の先頭へ並べ、1 件目を選ぶ。「1 件目で集中を開始」でそのまま始められる。

「今日は飛ばす」で閉じてもよい (振り返りに「飛ばした」と残る)。あとから開くときは「振り返り」ボタンの右クリックから。動いていないタスクは、一覧でも行の左端に小さな点が付く。

### 1 件選んで始める

1. 管理画面でタスクをダブルクリック (または Enter) して「次にやる 1 件」にする。
2. 「集中を開始」。Focus View だけになり、25 分計る。
3. 鳴ったら小休止。小休止中は Focus View で、溜まった一時メモを「タスクへ / 後で / 削除」に振り分ける。さっきまでのタスクを完了や待ちにもできる。
4. 小休止が終わると管理画面に戻る。次の 1 本は毎回自分で選ぶ (同じタスクなら「同じタスクでもう一度」)。

- **短い集中** (既定 10 分): 25 分が重いときの助走。ポモドーロには数えない。
- 鳴る前に終わったら、タイマーは止めずに残り時間の使い道 (見直す / 次をやる / 小休止へ) を聞く。早く終わっても 1 ポモドーロに数える。
- **小休止中の暗幕**: 全画面を暗くして手を止めさせる。クリックは素通しし、Focus View のボタンで外せる。濃さは設定から。
- **全画面**: Focus View をモニタ 1 枚に広げ、補助モニタの通知ごと覆う。一時メモの入力欄は画面の中央、タスク名のすぐ下に出る。
- **集中を始めるホットキー** (既定 Ctrl+Alt+P): どこからでも、選んでいるタスクで集中を始める。選んでいなければ管理画面が出る。
- **タイマーなしの作業の知らせ**: 平日の決めた時間帯 (既定 9:00〜18:00) に、タイマーを動かさずに PC を 15 分使い続けると、画面の右下に小さな窓が出る。ボタン 1 つで選んでいるタスクの集中に入れるほか、やっていたことを 1 行書けばそのタスクを作って始まる。どちらでも、それまでの時間は「タイマーなし」として記録に残る (ポモドーロには数えない)。× で閉じると 30 分は出ない。全画面のアプリ・プレゼン中も出ない。5 分操作が無ければ離席とみなして数え直し、管理画面を使っている間は数えない。
- **会議・休憩**: 予定に入っている会議や休憩の間は、タイマーなしの時間を数えない (ポモドーロの合間の「小休止」とは別)。知らせの「会議・休憩」か、管理画面の「次の予定」の横の「会議・休憩」で、種類と長さを選ぶ。会議は 30 分 / 1 時間 / 1 時間半 / 2 時間、休憩は 10 分 / 15 分 / 30 分 / 1 時間から選ぶか、終わる時刻を入れる。会議中・休憩中は、画面の右下に「会議中 〜14:30」のような小窓が出る。点の色は、会議がポモドーロと同じ橙、休憩が小休止と同じ緑。「＋15分」で延ばし、「終了」で早めに終えられる。小窓は右クリックで隠せる。隠しても会議・休憩は続き、管理画面のボタンのメニューから出し直せる。終わった時刻から数え直すので、会議や休憩の時間はタイマーなしの作業に入らない。休憩が終わると、小休止の終わりと同じく管理画面が前に出る。会議・休憩の途中で集中を始めると、そこで終わったことになる。
- **ノイズ**: 集中中に Focus View の波のボタンを押すと流れ、すぐ上に音量と音色のつまみが出る (音色は左端がブラウン、真ん中がピンク、右端がホワイト)。数秒かけて大きくなり、一時停止で止まって再開で戻る。小休止に入る・集中を終えると止まり、次の集中では押し直す。音はアプリの中で作るので、ネットワークも音声ファイルも要らない。

### タスク一覧

| したいこと | 操作 |
| --- | --- |
| 追加 | 見出しの「＋」で先頭に、一覧の余白をダブルクリックで末尾に。書いて Enter。足したタスク (サブタスクも) には、そのまま止まる (白い枠)。続けて + でサブタスクを足せる |
| 選ぶ / 外す | 行をダブルクリック。外すときはもう一度、またはタスク以外のどこかをダブルクリック |
| 名前を変える | 名前をクリックしてそのまま書き換え |
| 期限 | 追加した直後にカレンダーが開く。あとからは行の「期限」。マウスで開いたときは日を押した時点で確定 |
| メモ | 行の「メモ」。開くと装飾付きで読め、本文を押すと書ける (離れると読む形に戻る)。`**太字**` `*斜体*` `~~取り消し線~~` (二重線) `- 箇条書き` `- [ ] チェック付き` が使え、上の小さなボタンや Ctrl+B / Ctrl+I / Ctrl+Shift+X でも付けられる。チェックは読む形のまま押せる。箇条書きの行で Enter を押すと次の行にも頭が付く。URL やパスは色が付き、読む形では押せば、書くときは Ctrl+クリックで開く。Focus View のメモも同じ |
| サブタスク | 行の「＋」、または右クリックのメニュー。1 階層だけ。サブタスクに止まって + を押すと、同じ階層に足す。親のメニューの「完了したサブタスクを隠す」で、完了したものを件数だけの 1 行に畳める (親ごとに覚える)。待ちのサブタスクには ⏳ と橙の「待ち」札が付く |
| 並べ替え | 左端のグリップをドラッグ。行の中央に落とすとサブタスクになる |
| 完了 | チェックボックス (設定で「選ぶ」の意味にもできる) |
| 重要の印 | 右クリックのメニュー、または表 (下記) で上下にドラッグ。一覧では 🍅 の左に ★ |
| 待ち | 右クリックのメニューの「待ちにする」。何を待つか・いつまでかを入れる。「待ち N 件」の引き出しに畳まれる |
| いつか | 右クリックのメニューの「いつかへ回す」(S キー)。すぐはやらないが捨てたくないものを、普段の一覧から「いつか N 件」の引き出しへ外す。週の振り返りで見直し、「一覧に戻す」で戻す |
| 一時メモに戻す | 右クリックのメニュー。名前・メモ・サブタスクが 1 つの文章に畳まれる |
| 削除 | 行をクリックして Delete キー、または右クリックのメニュー。ゴミ箱に入り、戻せる。終了時に空になる |
| 戻す | Ctrl+Z / Ctrl+Y |

行のボタン (完了 or これをやる / 期限 / メモ / ＋ / ⋯) はマウスを載せるか、行に止まる (クリックかキーボード) と出る。「⋯」は右クリックと同じメニューを開く。**そのタスクにできることは全部、右クリックのメニューにある** (アプリケーションキーか Shift+F10 でも開く)。表のカードも同じ。

### 緊急度 × 重要度の表

タスクが増えてきたら、タスク欄の見出しの「表」でアイゼンハワーのマトリックスに切り替えられる (既定は一覧。次に開いたときは一覧に戻る)。

- 縦は「重要」の印、横は期限から自動で決まる (期限が 2 日以内か過ぎていれば緊急)。軸の見出しにカーソルを置くと基準が出る。
- マスの見出しは象限の番号・区分・次の一手を並べて **Ⅰ 緊急かつ重要：すぐやる / 重要だが緊急でない：計画する / 緊急だが重要でない：任せる / 緊急でも重要でもない：やらない**。それぞれに次の一手のボタン (次にやる / 期限を付ける / 待ちにする / 一時メモへ) が付いていて、カードを押してから使う。
- カードを上下にドラッグすると重要の印が付け外しされ、左右にドラッグすると期限が仮に置かれてカレンダーが開く。どちらも Ctrl+Z で戻せる。
- カードをダブルクリックすると「次にやる 1 件」になって一覧に戻る。集中を始めるのは今まで通り一覧から。
- 待ちのタスクは表には出ない (今は手を出せないため)。表の下の「待ち N 件」の引き出しで見る。
- 重要の印は一覧の行にも 🍅 の左に小さく出る。

### 一時メモ

割り込みと思いつきの置き場。ホットキー、欄の「＋」、欄の余白のダブルクリック、Focus View のタスク名のダブルクリックで入る。複数行を受ける (Shift+Enter で改行)。「タスクへ」で 1 行目が名前、全文がメモになる。

タスクの行と同じ作法で扱える。本文を押せば書き直し、それ以外の所を押せばその件に止まり、Delete で削除。載せると右下に「タスクへ」と「⋯」が出る。右クリック (か「⋯」) のメニューには、タスクへ / タスクにして次にやる 1 件にする / 書き直す / 本文をコピー / 削除 が並ぶ。

### 定型タスク

「メール確認」のような型は、一時メモ欄の下の「定型」に登録しておく。「追加」で 1 件タスクになる。周期 (毎日 / 毎週 / 毎月) を付ければその日に自動で追加される。逃した日の分は積まず、前の分が残っていれば次は追加しない。

### 振り返り

上の帯の「振り返り」で、管理画面の中身が振り返りに入れ替わる (「一覧に戻る」で戻る)。集中中・小休止中には出さない。点数や連続記録は出さず、数字は事実として並べるだけ。

- **今日**: ポモドーロ・集中した時間・完了・中断・集中中に書き留めた一時メモの数、1 日の流れ (集中した時間帯をタスクごとの色の帯で)、実行したタスク (完了 / 未完了 / 待ち と 🍅 の数)、集中の終わり方。今日を見ているときは「明日に備える」(未整理の一時メモ・期限の近いもの・催促の日が来た待ち) と「明日の最初の 1 件」(選んでおくと、アプリを開き直しても選ばれた状態で始まる) も出る。
- **今週**: 同じ数字、曜日ごとのポモドーロ数の棒グラフ、🍅 が多かったタスク、週次の見直し (一時メモを整理する → 待ちのタスクを見直す → 2 週間以内の期限を確認する → マトリクスの「Ⅱ」から来週やるタスクを決める → 「いつか」を見直す → 定型タスクを見直す。各項目から該当の画面を開ける)。
- 「今日」にはその日の朝の整理を済ませたか (済ませた / 飛ばした) と、知らせから記録したタイマーなしの時間 (流れの中に点線の枠で) も出る。
- 「今日」の 1 日の流れには、会議と休憩の時間も帯の下の細い段に出る。見出しの右の「会議・休憩も出す」で、出すかどうかを切り替えられる。
- どちらも一言メモを残せる (日・週ごとに 1 件)。← → で前の日・前の週をさかのぼれる。
- **業務報告のコピー**: 「今日」の画面の「業務予定をコピー」「業務実績をコピー」で、Teams などに貼る文章をクリップボードに入れる (「振り返り」ボタンの右クリックからも)。予定はタスク一覧の上から 3 件 (選んでいるタスクがあれば先頭)、実績はその日に実行したタスク (完了・未完了・待ち)。サブタスクは親の名前にまとめ、定型タスクは入れない。

```
＜業務実績＞
・B 社との契約書レビュー
・来期予算の説明資料を作る
```
- 設定で、決まった時刻に管理画面の上へ控えめな帯で知らせられる (今日は平日のみ、今週は曜日を選ぶ)。既定はどちらもオフ。

### 次の予定

画面下の「次の予定」に時刻を入れると、それまでに何本入るかを出す。1 本も入らなければ開始ボタンが止まる (無視して開始もできる)。

### キーボード

管理画面も Focus View もマウス無しで歩ける。↑ ↓ で行や部品を渡り、← → で行の中のボタン、Enter / Space で決定、Esc で戻る・選択を外す。

タスクや一時メモに止まっている (クリックかキーボードで細い枠が付いている) ときは、次のキーが効く (既定)。右クリックのメニューの各項目にも同じキーが書いてある。キーと、タスクの行に出すボタン (並びも) は、設定の「ボタンとショートカットキー」で変えられる。

| タスク | キー | 一時メモ | キー |
| --- | --- | --- | --- |
| 次にやる 1 件にする | Enter / Space | 書き直す | Enter / F2 |
| 完了 | C | タスクへ | T |
| 待ち | W | タスクにして次にやる 1 件にする | Shift+T |
| 名前を変える | F2 | 本文をコピー | Ctrl+C |
| 期限 | D | 削除 | Delete |
| メモ | M | メニュー | Shift+F10 |
| 重要 | I | | |
| サブタスクを追加 | + | | |
| いつかへ回す / 一覧に戻す | S | | |
| 削除 | Delete | | |
| メニュー | Shift+F10 | | |

### 設定

- 集中 / 短い集中 / 小休止の長さ、長めの小休止の間隔
- 次の予定の前に空ける時間
- Quick Capture のホットキー、集中を始めるホットキー
- 朝の整理を出すか、タイマーなしの作業を知らせるか (何分で・何時から何時まで)
- Focus View: 最前面、半透明 (次回起動で反映)、全画面
- チェックボックスの意味 (完了 / 選ぶ)
- 選択中に他のタスクを薄くする (会議中の片手間など、選んだだけで開始しないとき用)
- 小休止中の暗幕と濃さ
- 通知音、Focus View に一時メモの件数を出すか

## 数え方

- 1 ポモドーロ = 標準の集中 1 本。短い集中は数えない。
- 集中中に別のタスクへ切り替えると「中断」として記録する。同じ親の中での移動は数えない。
- 待ちのタスクは「次にやる」の候補から外れる。

## データ

exe と同じ場所に書き込める `data/` があればそこに保存する (ポータブル)。なければ `%LOCALAPPDATA%\PomoSingle\`。同じ場所の `startup.log` に、使ったフォルダ・ホットキーの登録結果・パスを開いた記録が残る。

## ビルド

```bash
npm install
npm run tauri dev                 # 開発
npm run tauri build -- --no-bundle  # 単体 exe → src-tauri/target/release/PomoSingle.exe
```

前提: Node.js 18+ / Rust stable (MSVC) / VS Build Tools (C++) / WebView2 ランタイム。

```bash
cd src-tauri && cargo test   # DB、定型、候補の並び
npm test                     # 本数の計算、リンクの切り出し
```

自前ビルドは未署名なので、初回に SmartScreen の警告が出る。`scripts\sign-portable.ps1` で自己署名を付けられる (改ざん検知と、証明書を入れた PC での警告回避)。
